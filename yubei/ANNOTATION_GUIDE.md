# YOLO 标注规范

一株水稻按同一个栽植点长出的一个茎蘖丛标注。一个图片可以标注多个完整植株，轻微交叠允许 bbox 互相重叠。严重交叠、无法判断叶片属于哪一株时，不把两株合成一个框，在网页中选择“跳过/歧义”。

整株训练图的 `rice_plant` 框覆盖一个完整植株可见的地上部分，不把明显属于盆、地面和其他植株的区域纳入。图片边缘只出现少量叶片时跳过，不强行标注。

稻穗训练图使用 `panicle`，每个独立可辨认的稻穗分别标框；重叠但边界可判断时仍分别标注。模糊、太小、被叶片遮挡到无法确认的区域标记歧义或跳过，不要猜测。当前两个训练会话不需要 Tag。

启动：

```bash
./yubei/start_yubei.sh label
```

网页支持画框、移动/删除、撤销/重做、复制上一张框、保存并下一张、歧义标记、质量差/重复图排除和 YOLO TXT 导出。类别从会话 manifest 读取。
