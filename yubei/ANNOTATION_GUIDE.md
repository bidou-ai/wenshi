# YOLO 标注规范

一株水稻按同一个栽植点长出的一个茎蘖丛标注。一个图片可以标注多个完整植株，轻微交叠允许 bbox 互相重叠。严重交叠、无法判断叶片属于哪一株时，不把两株合成一个框，在网页中选择“跳过/歧义”。

`rice` 框覆盖一个完整植株可见的地上部分，不把明显属于盆、地面和其他植株的区域纳入。图片边缘只出现少量叶片时跳过，不强行标注。

`flower` 表示图中能够明确辨认的开花部位，不表示整株“处于开花状态”。一处连续、可清楚辨认的花部使用一个紧框；
不同位置的花部分别标框。模糊、太小、被叶片遮挡到无法确认的区域不要猜测。开花批次 `capture_tag=flower`
只是采集时的筛选备注，不会自动生成 `flower` 标签。

启动：

```bash
./yubei/start_yubei.sh label
```

网页支持开花批次筛选、100%–300% 放大、画框、移动/删除、选中框改类别、撤销/重做、复制上一张框、
保存并下一张、歧义标记、质量差/重复图排除和 YOLO TXT 导出。
