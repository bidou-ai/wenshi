# YOLO 标注规范

一株水稻按同一个栽植点长出的一个茎蘖丛标注。一个图片可以标注多个完整植株，轻微交叠允许 bbox 互相重叠。严重交叠、无法判断叶片属于哪一株时，不把两株合成一个框，在网页中选择“跳过/歧义”。

首版只使用 `rice` 标签；`flower` 保留为类别 1，后续有花的样本再启用。框应覆盖主体可见的地上部分，不把明显属于盆、地面和其他植株的区域纳入。图片边缘只出现少量叶片时跳过，不强行标注。

启动：

```bash
python3 yubei/label_server.py --session yubei/data/dataset_...
```

网页支持画框、移动/删除、撤销/重做、复制上一张框、缩放、类别选择、歧义跳过、自动保存和 YOLO TXT 导出。
