# 32 株表型与文档收敛实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 Wenshi 迁移为四排各 8 株、16 个停车观测组的表型系统，并收敛为可维护的中文 `docs/` 文档体系。

**Architecture:** 保持一停车点两株、每株三视角、每株恰好一次覆盖的协议，只扩展配置、校验与调度。文档分为现行操作/技术资料和归档；`README.md` 是 GitHub 项目入口。

**Tech Stack:** Python 3、PyYAML、pytest、Bash、Markdown、Git。

**Spec:** `docs/superpowers/specs/2026-08-28-32株文档与表型迁移设计.md`

## Global Constraints

- 正式范围只含株高和有效穗数；旧 rice/flower、倒车、J5 跟随和固定抵近是历史原型。
- 布局是 `A/B-L/B-R/C` 四排各 `01..08`，`left/right-01..08` 共 16 个停车观测组。
- 每组恰好两株、每株恰好一次覆盖；不改三视角和两株完成后恢复路线协议。
- `phenotyping.enabled` 保持 `false`，不得虚构 Tag、停车点、姿态、相机或水位标定。
- `docs/` 下 Markdown 名称与目录必须使用中文；根目录 `README.md` 保持标准文件名。
- 不启动或驱动 AGV、JAKA、D435。
