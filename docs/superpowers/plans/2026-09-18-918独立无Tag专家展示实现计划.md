# 9.18 独立无 Tag 专家展示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 `9.18.sh` 独立专家展示，支持新 `.smap`、动态路线/观察点、无 Tag setup，以及与现有 Demo 相同的巡航、对中、机械臂观察和 RViz 流程。

**Architecture:** `demo_918_setup.py` 独占新场地 schema、证据和地图快照；`demo_918.py` 独占交互 setup 与运行控制器。两个模块只复用 AGV/JAKA 客户端、路线数学、地图解析等底层组件，不读取旧 Demo 业务数据。`9.18.sh` 使用独立配置和运行目录，但与 `wenshi.sh` 共享硬件锁。

**Tech Stack:** Python 3.10、pytest、OpenCV、PyYAML、ROS2 Humble/rclpy、Bash、现有 AGV TCP 与 JAKA 客户端。

**Spec:** `docs/superpowers/specs/2026-09-18-918独立无Tag专家展示设计.md`

## Global Constraints

- 不修改或读取 `runtime/demo/` 作为 9.18 运行依赖，不写 `runtime/height_tests/`。
- 不要求 Tag、标定板、固定排数、固定观察点数量或 LM1-LM4。
- setup 不发送 AGV/JAKA 运动命令；运行前所有现场数据必须通过独立 loader 校验。
- 巡航上限 0.18 m/s，末端 0.60 m 减速，最低 0.04 m/s，观察前 3 度对中。
- JAKA 观察 50 deg/s、回撤 60 deg/s、加速度 80 deg/s2。
- 普通行驶和原地对中必须与 pause/stop 共用状态锁，状态切换后不能补发运动命令。
- 所有手工代码编辑使用 `apply_patch`；不覆盖工作区已有修改。
