# 视觉状态

当前状态：**代码已准备，默认未启用**。

项目保留了 YOLO 检测封装、图像采集、RGB-D 几何基础和运行记录接口，但没有经过验证的水稻
模型、类别定义、数据集、手眼标定或视觉引导运动逻辑。`collect` 可用于人工采图；`detect` 在
`vision.enabled=false` 时会明确拒绝，不会把“模型缺失”伪装成“零目标”。

启用识别前必须补齐：模型文件和哈希、类别清单、离线评估报告、采集/标注数据版本、相机内参与
手眼标定、深度有效区验证、多帧确认策略、机械臂工作空间评估以及人工实机验收记录。即使完成这些，
第一阶段也只能记录结果，不能让视觉直接控制 AGV 或 JAKA。正式 demo 默认只配置 `rice`；`flower` 类别和
标注界面已预留，不会在没有数据和评估报告时被误判为可用。
