# 视觉状态

当前状态：**代码已准备，默认未启用**。

项目已经实现 YOLO 检测封装、图像采集、RGB-D 深度统计、彩色/对齐深度尺寸映射、稳定目标选择、J5跟随、受控后退、
固定示教抵近、远近景质量检查、去重和运行记录，但没有经过验证的水稻模型、现场数据集、
完整八点示教、距离参数或实机验收。`collect` 可用于人工采图；`detect` 在
`vision.enabled=false` 时会明确拒绝，不会把“模型缺失”伪装成“零目标”。

启用前必须补齐：模型文件和哈希、类别清单、离线评估报告、采集/标注数据版本、深度有效区验证、
八点示教、机械臂工作空间评估、后退距离和安全条件以及人工实机验收记录。目标框内零深度或无效深度
会阻止目标后退；启用目标任务时离线预检还会检查 `ultralytics` 是否安装。视觉模块本身不直接持有
AGV/JAKA客户端；只有主协调器在全部互锁通过后进入专用目标状态。正式 demo 默认只检测 `rice`；
`flower` 类别和标注界面已预留，不会在没有数据和评估报告时被误判为可用。
