# 项目状态

更新时间：2026-08-28。现场未测量的项目均标为未完成。

## 本期目标

观测 24 株水稻的株高和有效穗数。每株三视角 `left`、`center`、`right`；AGV 按 12 个逻辑停车位置组织，每次覆盖相对的两株。

## 已完成的软件基础

- 表型配置和 schema：24 个唯一株号、12 个 observation group、禁用时的占位配置和正式就绪判断。
- Tag25h7 适配器：可注入检测 backend，支持 `matched`、`missing`、`mismatched`、`unconfirmed`，拒绝重复 ID。
- 单株存储：`run.json`、`events.jsonl`、`agv.csv`、`jaka.csv`、三视角媒体、帧元数据、trait JSON 和 `review.json`；支持原子写入和中断恢复。
- 株高：沿 3D 折线计算弧长，支持补偿优先级，保存自动路径、自动值、人工路径、人工值和差值。
- 有效穗：候选标准化、跨视角合并、拆分、删除、新增、状态修改和操作历史；支持 `confirmed`、`suspected`、`occluded`、`duplicate`、`deleted`。
- 表型只读后台：运行列表、运行详情、单株详情、媒体读取和 CSV 导出。
