# 操作手册

现场操作先由人员完成上电、使能、急停和工作区检查。程序不会自动清报警、上电或使能；进入运动前必须有人看护。

## 入口

现场测试：

```bash
cd /home/ubuntu/jaka/wenshi
./scripts/start_field_test.sh
./scripts/start_field_test.sh --no-rviz
```

进入 `field>` 后可用 `camera`、`camera stop`、`teach`、`test route`、`test arm`、`status`、`stop`、`q`。`teach` 中人工摆位后按回车保存当前点并自动进入下一个；它不发送运动命令。八个点为 `home_safe`、`camera`、`camera_left`、`camera_right`、`left_pre`、`left_photo`、`right_pre`、`right_photo`。`test arm` 才会逐点运动。

准备工具：

```bash
./yubei/start_yubei.sh check
./yubei/start_yubei.sh camera-check
./yubei/start_yubei.sh capture
./yubei/start_yubei.sh audit
./yubei/start_yubei.sh label
./yubei/start_yubei.sh prepare
./yubei/start_yubei.sh train
./yubei/start_yubei.sh teach
./yubei/start_yubei.sh verify
./yubei/start_yubei.sh publish-viewpoints --confirm
```

正式旧巡检入口为 `./scripts/start_wenshi.sh`；只检查用 `./scripts/start_wenshi.sh --check`。`./scripts/start_wenshi.sh phenotype` 会在当前未标定配置下安全退出，不要修改安全锁绕过预检。

## 表型配置和数据

表型配置位于 `config/wenshi.yaml` 的 `phenotyping`、`april_tag`、`plants` 和 `observation_groups`。当前 24 个株号存在，但 Tag ID、Tag 高度和 12 个停车参数为 `null`。Tag 固定在对应水稻的卡槽前，方向可以向上或侧放，现场确认后写入配置。

表型目录：

```text
runtime/runs/run_<timestamp>/
  run.json events.jsonl agv.csv jaka.csv
  plants/<plant_id>/plant.json review.json
  plants/<plant_id>/captures/{left,center,right}/
  plants/<plant_id>/traits/{plant_height,effective_panicle_count}.json
```

株高是三维路径弧长加卡槽到水面的补偿；缺深度、遮挡、路径歧义或补偿缺失时保持 `needs_review`。有效穗候选必须跨视角合并，最终以人工确认值为准。

## 后台和相机

```bash
./scripts/start_dashboard.sh
```

默认地址为 `http://127.0.0.1:8088/`，按 `Ctrl+C` 停止。后台当前提供表型只读查看和 CSV 导出，不提供运动按钮或浏览器编辑接口。Windows 相机可运行 `start_camera_server.bat`，或 `py windows_realsense_server.py --host 0.0.0.0 --port 18080`。

AGV、JAKA 和相机电脑留在机器人内网；Ubuntu 另一路连接温室 Wi-Fi 上公网。当前地址约定为 AGV `192.168.192.5`、JAKA `192.168.192.160`、D435 `192.168.192.203:18080`，以配置和检查结果为准。

## 故障处理

- 相机断流或帧过期：停止相关运动，检查 Windows `/health`、`camera_console.log` 和网络。
- Tag 缺失或不匹配：保留 `missing`/`mismatched`，不要猜测株号；重拍或标记补采。
- JAKA/AGV 报警、定位过期、急停或人员进入区域：先实体急停，再输入 `stop`，人工确认后重新预检。
- 表型算法失败：不得触发运动；保留原图、事件和 `needs_review` 原因。

旧 `rice` 抵近、倒车、J5 跟随和固定抵近只属于旧原型，当前安全配置默认禁止。
