# 控制与测量报告

## 1. 范围

本报告规定本期 24 株、12 个停车位置、三视角 RGB-D 采集、株高和有效穗数的控制边界与证据要求。它不是现场验收结果；空白项必须由现场测量和日志补齐。

## 2. 控制边界

路线保持 `LM1 -> LM4 -> LM3 -> LM2`。机器人从中间区左、右通道观察两侧植株，每次停车覆盖相对两株，底盘停稳后才采集。AGV 地图进度负责粗定位，Tag 负责身份和局部触发，不承担全局导航。

Tag 固定在对应水稻的卡槽前，允许朝天或侧放；必须记录 `upward` 或 `side`。Tag 到水面高度当前未标定，不能用于正式补偿。

## 4. 采集证据

```text
run.json                 批次和配置快照
events.jsonl             身份、停车、采集、失败和复核事件
agv.csv / jaka.csv       控制状态采样
plants/<id>/plant.json   株号、Tag、视角和状态
captures/<view>/         color.jpg、depth.png、frame.json
traits/*.json            自动值、人工值、路径、状态和原因
review.json              单株复核状态和更新时间
```

写入必须原子完成。缺失深度记录为 `null`，不能伪造。Tag `missing`、`mismatched`、`unconfirmed` 和重复 ID 均保留诊断。

## 5. 株高

株高不是画面最高点到水面的直线距离。路径为：`卡槽/水面基准 -> 同一根茎秆中心线 -> 穗轴 -> 最高穗顶`。软件沿 3D 折线求弧长，再加 `slot_to_water_offset_m`。保存自动路径、人工路径、自动值、人工值和差值。深度不足、遮挡、路径歧义、补偿缺失、非有限值或超范围必须为 `needs_review`。

## 6. 有效穗

有效穗是能够看清并确认已经长出的穗子。每视角保存候选位置、置信度、可见度和深度；跨视角合并后允许人工合并、拆分、新增、删除或改状态。状态为 `confirmed`、`suspected`、`occluded`、`duplicate`、`deleted`。`automatic_value` 只作候选统计，`reviewed_value` 才是正式数量。

## 7. 对照和验收

每株记录批次、操作者、日期、配置版本、Tag、位置、三视角完成情况、人工值、自动值、差值、缺陷和补采结果。当前没有精度阈值，先生成误差报告，不自行宣称准确率或放行。验收顺序为：单 Tag、单视角、一位置两株、左 6 位置、右 6 位置、24 株、后台复核、补采和中断恢复。

旧花时、rice 识别、目标抵近、底盘后退、J5 跟随、固定抵近和 `far/near` 存储不属于本报告。
