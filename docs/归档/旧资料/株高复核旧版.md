# 株高候选与人工复核

## 测量规则

株高定义为卡槽顶部到最高穗顶的植物中心线三维弧长，再加上卡槽顶部到水面的补偿值。结果单位为米，后台可以换算为厘米显示。

首版不把图像最高像素当作株高，也不使用不可解释的回归模型。输入路径由算法候选或人工在 RGB-D 图像上编辑得到，路径点包含相机坐标系下的三维坐标。

## 补偿优先级

补偿按以下顺序选择：单株值、区域默认值、全局默认值。缺失、非有限或负数补偿都视为缺失。补偿尚未现场测量时，候选保持 `needs_review`，不会生成正式自动值。

## 结果字段

`plant_height.json` 至少保留：

- `auto_value_m` 和 `auto_path_3d`：自动候选及其证据；
- `reviewed_value_m` 和 `reviewed_path_3d`：人工编辑路径重新计算的结果；
- `difference_m`：人工值减自动值；
- `slot_to_water_offset_m`、`path_length_from_slot_m`、`views_used`；
- `quality` 与 `reasons`；
- `reviewed_by`、`reviewed_at`。

## 必须人工复核

以下任一情况都不能放行自动值：深度非有限或大面积缺失、最高穗出画、茎秆或穗轴遮挡、路径进入邻株、跨视角路径不一致、补偿缺失、结果超出配置范围，或路径无法确定。

复核员应在可用视角中编辑水面/卡槽基准、茎秆中心线和最高穗顶路径。保存时沿编辑后的三维折线重新计算弧长，并保留原自动候选，不覆盖历史证据。

本模块只做硬件无关的几何计算；它不连接 AGV、JAKA、D435，也不负责决定是否重拍或继续任务。
