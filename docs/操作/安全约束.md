# 安全约束

## 不可绕过的边界

- 程序不得发送 JAKA 上电、使能、下电或清报警命令。
- `phenotyping.enabled` 为 `false` 时，表型预检必须拒绝正式执行；Tag、停车点、表型姿态、相机或水面补偿缺失时同样拒绝。
- AGV 定位过期、急停、报警、阻挡、运动端口断开或横向偏差超限时，必须停止运动。
- 采图拒绝超过 `camera.frame_max_age_s` 的彩色缓存帧；深度缺失必须明确保存为缺失，不能补造数值。
- 视觉、表型算法、存储和后台不持有 AGV/JAKA 运动客户端；算法结果不能直接触发运动。

## 现场操作

仅在人员看护、工作区清空、底盘停稳且相关前置验收完成后，才可进行相应现场动作。`teach` 是人工摆位后读取保存，不发送运动；`test arm` 和 `test route` 才可能执行运动，且不属于 32 株表型放行。

出现风险时，先实体急停，再输入 `stop`，确认底盘和机械臂静止后诊断。不得通过临时修改 `vision.enabled`、`patrol_target.enabled`、`fixed_approach.enabled`、倒车开关或预检逻辑绕过约束。

## 旧原型限制

倒车、J5 跟随、固定抵近和旧 `rice` 目标流程不是当前表型功能。后雷达未验证且倒车安全锁关闭时不得启用倒车；固定抵近默认关闭，不能替代 16 点、Tag、三视角和标定验收。
