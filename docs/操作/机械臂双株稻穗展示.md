# 机械臂双株稻穗展示

本流程用于固定底盘、两株均在机械臂左侧的现场专家展示。它只控制 JAKA 和读取 D435，
不启动或控制移动底盘。右栏显示的是稻穗检测候选框，候选框数量不是有效穗数，整个流程也不测量株高。

## 现场顺序

1. 确认底盘固定、人员已退出机械臂工作区；一人始终手持实体 E-stop。确认示教器可用，现场已完成每条边的碰撞检查。
2. 在项目根目录先执行示教：`./arm_demo.sh --setup`。按屏幕提示，用示教器依次摆好十个姿态后按 Enter：`home_safe`、`left_clearance`、`rice1_pre`、`rice1_center`、`rice1_scan_a`、`rice1_scan_b`、`rice2_pre`、`rice2_center`、`rice2_scan_a`、`rice2_scan_b`。中断后以 `./arm_demo.sh --setup --resume runtime/arm_demo/setup_<timestamp>` 继续。
3. 先执行 `./arm_demo.sh --dry-run`，仅校验配置、模型与 setup；它不连接相机或机械臂，也不创建窗口。
4. 用 `./arm_demo.sh --test-once` 做一次低速验收。界面出现后必须按 Space 才会运动；完成两株和返回 `home_safe` 后不再循环。
5. 通过现场验收后运行 `./arm_demo.sh` 进行连续展示。每轮从 `home_safe` 经 `left_clearance` 到水稻 1，再回 `left_clearance` 到水稻 2，最后回 `home_safe`；下一轮交换两株先后顺序。

每株路径固定为 `left_clearance -> riceN_pre -> riceN_center -> riceN_scan_a -> riceN_center -> riceN_scan_b -> riceN_center -> riceN_pre -> left_clearance`。禁止临时加减关节角或从一株近景直接移动到另一株近景。

## 窗口操作与故障

- Space：在 READY 开始；在 RUNNING 立即暂停。
- H：仅在 HOLD 时按已示教边安全回撤到 `home_safe`。
- P：保存当前双栏画面到 `runtime/arm_demo/photos/`。
- Q、Esc 或关闭窗口：立即停止并退出，保持当前位置，不自动回家。

出现 ERROR 时程序已停止运动，但不会自动回家。操作者必须先用 E-stop/示教器确认现场安全并处理故障；不得用 H 试图从 ERROR 自动恢复。
