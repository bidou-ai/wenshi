# 机械臂双株稻穗展示

本流程用于固定底盘、两株均在机械臂左侧的现场专家展示。它只控制 JAKA 和读取 D435，
不启动或控制移动底盘。右栏显示的是稻穗检测候选框，候选框数量不是有效穗数，整个流程也不测量株高。

## 现场顺序

1. 确认底盘固定、人员已退出机械臂工作区；一人始终手持实体 E-stop。确认示教器可用，现场已完成每条边的碰撞检查。
2. 在 Ubuntu 确认 D435 和 JAKA 可达：先运行 `./scripts/start_field_test.sh`，RViz 持续显示 D435 RGB 即证明演示使用的 `/frame` 取流链路正常，退出现场测试后再启动本演示；`nc -vz -w 3 192.168.192.160 10001` 必须成功。本演示和现场测试一样，每次只请求一次 `/frame`，不再另外轮询 `/health` 和 `/snapshot.jpg`。TCP 成功只代表端口可达，JAKA 最终仍以程序能读取新关节状态为准。
3. 在项目根目录执行示教：`./arm_demo.sh --setup`。用示教器依次摆好十个姿态：`home_safe`、`left_clearance`、`rice1_pre`、`rice1_center`、`rice1_scan_a`、`rice1_scan_b`、`rice2_pre`、`rice2_center`、`rice2_scan_a`、`rice2_scan_b`。每次都先点击 `Arm Demo Setup` 预览窗口使其获得焦点，再在该窗口按 Enter；不要在终端按 Enter。程序会为该姿态临时建立只读 JAKA 连接、连续读取三次关节状态、保存照片后立即断开，并在终端打印 `已登记 <name>（n/10）`。
4. 单次 D435 预览超时会保持当前姿态并自动重试，不会退出 setup。某一姿态的 JAKA 读取失败时，程序同样不推进进度；保持机械臂不动，在预览窗口再次按 Enter。按 Q/Esc 或 Ctrl+C 会保留草稿。使用终端已打印的命令恢复，格式为 `./arm_demo.sh --setup --resume runtime/arm_demo/setup_<timestamp>`。
5. 十个姿态全部完成并生成 `runtime/arm_demo/demo_setup.json` 后，执行 `./arm_demo.sh --dry-run`。它只校验配置、模型与 setup，不连接相机或机械臂；看到 `dry-run: config/model/setup validated; no hardware connection` 才算通过。
6. 执行 `./arm_demo.sh --test-once` 做一次低速验收。程序会读取当前关节角：在已示教姿态或相邻示教点之间时，直接沿白名单反向路径自动回到 `home_safe`；已离开路径但能唯一匹配最近姿态、且任一关节偏差不超过 `20 deg` 时，先以低速接入该姿态，再沿白名单路径回家。自动回家最高 `20 deg/s`；超过 `20 deg` 或最近姿态不唯一时仍禁止自动运动。自动回家完成并打开双画面后，按 Space 开始不超过 `5 deg/s` 的单轮；一人手持实体 E-stop，逐段确认机械臂只沿示教路径运动。完成两株观察并返回 `home_safe`、界面重新显示 READY 才算通过。
7. 低速验收通过后执行 `./arm_demo.sh` 连续展示。自动回家并打开双画面后会自动开始，不需要按 Space。默认过渡、接近、观察摆动速度分别为 `45/30/15 deg/s`。每轮从 `home_safe` 经 `left_clearance` 到水稻 1，再回 `left_clearance` 到水稻 2，最后回 `home_safe`；下一轮交换两株先后顺序。

每株路径固定为 `left_clearance -> riceN_pre -> riceN_center -> riceN_scan_a -> riceN_center -> riceN_scan_b -> riceN_center -> riceN_pre -> left_clearance`。禁止临时加减关节角或从一株近景直接移动到另一株近景。

## 窗口操作与故障

- Space：在 READY 开始；在 RUNNING 立即暂停并进入 HOLD。
- H：仅在 HOLD 时按已示教边安全回撤到 `home_safe`；正常结束展示时，先按 Space 暂停，再按 H 并等待界面显示 READY。
- P：保存当前双栏画面到 `runtime/arm_demo/photos/`。
- Q 或 Esc：立即停止并退出，保持当前位置，不自动回家。也可在终端按 Ctrl+C 退出。

Wayland 下窗口可见性状态不可靠，不要依赖点击窗口 X 停止程序。正常收尾应在预览窗口依次按 Space、H，等待 READY 后再按 Q/Esc；紧急退出可在终端按 Ctrl+C，但不会自动回家。
D435/检测只用于展示，不是固定示教路线的安全互锁。视觉链路超过 `5s` 未更新时，窗口显示 `VISION RECONNECTING`，终端打印告警并继续自动重试，机械臂仍按已示教路线循环；图像恢复后会打印 `视觉链路已恢复`。

出现 ERROR 时程序已停止运动，但不会自动回家。操作者必须先用 E-stop/示教器确认现场安全并处理故障；不得用 H 试图从 ERROR 自动恢复。
