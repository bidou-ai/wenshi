# 标签映射与现场确认

## 规则

表型身份标识固定为 `tag25h7`。现场编号已经确定：A 排自上而下为 `1..8`，B-L 排为 `16..9`，B-R 排为 `17..24`，C 排为 `32..25`。`0` 只作为标定板，绝不分配给植株。

现场逐株记录：Tag ID、株号、观测组、实际方形边长（黑色外框 9 cm；中间编码区约 6 cm 不作为尺寸）、`upward` 或 `side` 朝向、可见性、倾角、遮挡说明和卡槽到水面高度。`setup --interactive` 会保存 ID 0 标定板照片和 32 张 Tag 同框照片；当前向导是人工确认编号，不把未验证的自动识别结果冒充身份确认。Tag 用于局部身份确认与触发；AGV 地图进度仍负责粗定位。

## 32 株与 16 组对应

| 观测组 | 通道左侧植株 | 通道右侧植株 |
| --- | --- | --- |
| `left-01` 至 `left-08` | `A-01` 至 `A-08` | `B-L-01` 至 `B-L-08` |
| `right-01` 至 `right-08` | `B-R-01` 至 `B-R-08` | `C-01` 至 `C-08` |

同一行中编号一一对应，例如 `left-03` 覆盖 `A-03` 与 `B-L-03`，`right-03` 覆盖 `B-R-03` 与 `C-03`。每组两株、每株恰好一次；映射不完整、重复 ID、缺失 Tag 或与预期株号不一致时必须拒绝身份确认。

## 写入与放行

确认后，程序将映射、照片证据和停车点写入 `runtime/height_tests/setup_<timestamp>/`，并发布 `runtime/height_tests/field_height_setup.json`。任何 Tag、照片、停车点、姿态或测量字段未确认时，正式表型入口仍保持拒绝。
