# 标签映射与现场确认

## 规则

表型身份标识固定为 `tag25h7`。每株需要一个可追溯的 Tag，但当前配置中 32 个 `tag_id`、Tag 实际边长、检测后端、安装朝向和卡槽到水面的高度均未确认，必须保持未标定状态，不能从图像或旧示例推断。

现场逐株记录：打印 Tag ID、株号、观测组、实际方形边长（米）、`upward` 或 `side` 朝向、可见性、倾角、遮挡说明和卡槽到水面高度。Tag 用于局部身份确认与触发；AGV 地图进度仍负责粗定位，不为每株新建地图站点。

## 32 株与 16 组对应

| 观测组 | 通道左侧植株 | 通道右侧植株 |
| --- | --- | --- |
| `left-01` 至 `left-08` | `A-01` 至 `A-08` | `B-L-01` 至 `B-L-08` |
| `right-01` 至 `right-08` | `B-R-01` 至 `B-R-08` | `C-01` 至 `C-08` |

同一行中编号一一对应，例如 `left-03` 覆盖 `A-03` 与 `B-L-03`，`right-03` 覆盖 `B-R-03` 与 `C-03`。每组两株、每株恰好一次；映射不完整、重复 ID、缺失 Tag 或与预期株号不一致时必须拒绝身份确认。

## 写入与放行

确认后，将每株 `tag_id`、`slot_top_to_water_m` 和全局 `april_tag.physical_size_m`、`detector_backend`、`mounting_orientation` 写入 `config/wenshi.yaml`。同时保存现场测量原始记录。任何字段未确认时，`phenotyping.enabled` 保持 `false`，预检拒绝正式表型任务。
