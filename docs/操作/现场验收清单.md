# 现场验收清单

未验证项必须记录为未验证。任何报警、急停、人员进入工作区、通信中断或姿态异常，先实体急停并确认停止；不得为了继续测试修改安全锁。

## 1. 离线基线

- [ ] `PYTHONPATH=app:. python3 -m pytest -q` 通过。
- [ ] `PYTHONPATH=app:. python3 -m wenshi_patrol.phenotype_controller --check --config config/wenshi.yaml` 明确拒绝未标定的正式表型任务。
- [ ] 确认 `phenotyping.enabled` 仍为 `false`，不把模拟或离线测试写作现场通过。

## 2. 网络、相机与 Tag

- [ ] Windows D435 服务的 `/health` 可访问，并记录连续 RGB-D 帧的时间戳、分辨率和深度状态。
- [ ] 逐株记录 32 个 Tag 的实际 ID、实际边长、`upward` 或 `side` 朝向、可见性和卡槽到水面的测量值。
- [ ] 在目标 Ubuntu 环境验证选定的 `tag25h7` 检测后端；不得假定任意 OpenCV 都支持该 family。
- [ ] 将确认值写入 `config/wenshi.yaml`，保留测量证据和日期；未确认字段继续为 `null`。

## 3. 16 个停车观测组

- [ ] `left-01` 至 `left-08` 各覆盖 `A-01..08` 与 `B-L-01..08`。
- [ ] `right-01` 至 `right-08` 各覆盖 `B-R-01..08` 与 `C-01..08`。
- [ ] 每组记录路线段、沿线距离、减速距离、触发距离、实际停车误差和两株身份。
- [ ] 每株仅被一个观测组覆盖一次；不得以旧版记录替代当前的 16 点、32 株标定。

## 4. 相机、姿态与单组试验

- [ ] 底盘停稳后，分别验证一组两株的 `left`、`center`、`right` 表型姿态。
- [ ] 每个视角验证 Tag 身份、RGB-D 同步、帧新鲜度、图像质量和 `frame.json` 证据。
- [ ] 验证相机内参、深度尺度、RGB-D 对齐、手眼关系和水面补偿；记录证据来源。
- [ ] 失败视角按限制重试，仍失败则标记补采，不能伪造完整三视角。

## 5. 扩展验收与复核

- [ ] 从一停车组两株扩大到左八组、右八组，最后核对 32 株恰好一次覆盖。
- [ ] 每株保留人工株高和有效穗对照；按[株高复核规范](株高复核规范.md)与[有效穗复核规范](有效穗复核规范.md)复核。
- [ ] 在后台确认运行、单株、媒体和 CSV 导出可读；后台不得出现运动控制功能。
- [ ] 记录中断、补采和恢复结果后，再评审正式表型运动编排。

本清单不由 `field_test_20260828_034122` 替代。该日志只包含教学、机械臂和路线测试事实，不覆盖 32 株表型验收。
