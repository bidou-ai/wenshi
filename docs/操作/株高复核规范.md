# 株高复核规范

## 测量定义

株高不是画面最高像素到水面的直线距离。以卡槽顶部或已确认的水面为基准，沿同一根茎秆中心线、穗轴到最高穗顶的三维路径求弧长；使用卡槽顶部时，加上已现场测量的 `slot_top_to_water_m` 补偿。存储单位为米。

## 候选与人工复核

自动候选保留 `auto_path_3d`、`auto_value_m`、路径长度、补偿值、使用视角、质量和原因。复核员在可用 RGB-D 视角中编辑基准、同一根茎秆和穗轴路径，再由系统重算 `reviewed_value_m`；保存 `reviewed_path_3d`、复核人、时间和与自动值的差值，不覆盖原始候选。

深度不足、遮挡、路径歧义、邻株混入、最高穗出画、补偿缺失、非有限值或超范围时必须是 `needs_review`。未完成相机、深度、手眼和水面补偿标定时，候选不构成正式测量结果。

## 一键测试中的方法层

`height_test` 会同时保存以下结果：M0 `bbox_pixel_height`（仅像素诊断）；M1 `tag_panicle_3d`（Tag/穗顶 RGB-D 三维垂直高度）；M2 `depth_roi_envelope`（植株 ROI 的三维深度包络）；M3 `mask_envelope`（颜色分割包络诊断）；M4 `manual_endpoints_3d`（人工点选基准和穗顶）；M5 `manual_stem_path_3d`（人工点选茎秆中心线弧长诊断）。

主候选优先使用 M1/M2/M4，M0、M3、M5 用于诊断和复核。各视角候选分歧超过配置阈值、深度有效率不足或人工对照超差时，保留全部方法值并标记 `needs_review`，不自动选择看起来“最好”的单个框。
