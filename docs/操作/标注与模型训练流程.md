# 标注与模型训练流程

## 当前目标

训练两个相互独立的单类别检测模型：

| 模型 | 类别 | 用途 |
| --- | --- | --- |
| 整株模型 | `rice_plant` | 找到完整水稻植株 |
| 稻穗模型 | `panicle` | 找到每一个独立稻穗 |

当前训练采集不需要 Tag。Tag 以后用于正式巡检时确认植株身份，不参与本次采集、标注和训练。

## 已有原始数据

```text
整株：yubei/data/plant/dataset_20260828_154448_562619
      20 张，10 株，每株连续 2 张

稻穗：yubei/data/panicle/dataset_20260828_150142_729627
      90 张，10 株，每株 9 张
      每株依次为正面 3 张、左侧 3 张、右侧 3 张
```

这批数据用于第一版模型和流程验证，不代表最终泛化精度。

## 一、生成训练副本

```bash
cd /home/ubuntu/jaka/wenshi
./yubei/start_yubei.sh normalize-plant yubei/data/plant/dataset_20260828_154448_562619
./yubei/start_yubei.sh normalize-panicle yubei/data/panicle/dataset_20260828_150142_729627
```

整株图片默认顺时针旋转 90 度。稻穗图片保留原始横向方向，不强行旋转。两个命令都生成新副本，原始目录不变。先打开副本确认图片方向，再进行标注。

## 二、人工标注

整株：

```bash
./yubei/start_yubei.sh label yubei/data/plant/dataset_normalized_dataset_20260828_154448_562619
```

每张图框当前整株水稻的可见主体，类别为 `rice_plant`。不要框旁边植株、机械臂、相机外壳或反光。

稻穗：

```bash
./yubei/start_yubei.sh label yubei/data/panicle/dataset_normalized_dataset_20260828_150142_729627
```

每个独立可辨认的稻穗分别画一个 `panicle` 框。一张图有 6 个稻穗就画 6 个框；重叠但边界可判断时仍分别标注。边界完全无法判断时标记歧义。叶片、茎秆、机械臂和背景不标注。

## 三、质量筛选

连续三张只有一张清晰时，只保留清晰的一张；另外两张只有在姿态、遮挡或清晰区域明显不同的情况下才保留。质量差、严重裁切、强反光、机械臂遮挡或完全重复的图片标记为跳过；无法判断稻穗边界的图片标记为歧义。

整株每 2 张属于同一株，稻穗每 9 张属于同一株。不要把同一株的图片随机拆到训练集和验证集。

## 四、准备训练集

```bash
./yubei/start_yubei.sh prepare-plant yubei/data/plant/dataset_normalized_dataset_20260828_154448_562619
./yubei/start_yubei.sh prepare-panicle yubei/data/panicle/dataset_normalized_dataset_20260828_150142_729627
```

程序会生成独立的 `data.yaml`，并按连续图片分组，避免同一株同时出现在 train 和 val。当前 10 株样本只能用于第一版流程验证。

## 五、训练两个模型

```bash
python3 -m pip install -r requirements-ubuntu.txt
./yubei/start_yubei.sh train-plant
./yubei/start_yubei.sh train-panicle
```

输出目录：

```text
yubei/training/plant/
yubei/training/panicle/
```

`train-plant` 会校验类别必须为 `rice_plant`，`train-panicle` 会校验类别必须为 `panicle`。训练不会自动发布模型，也不会连接 AGV、JAKA 或正式表型流程。

## 六、训练后检查

- 检查 train/val 是否按植株分开。
- 检查整株框是否漏掉顶部、底部或主体。
- 检查稻穗是否漏框、重复框或错误拆分。
- 检查模型是否把叶片、机械臂、反光和背景当成目标。
- 不把检测框数量直接当作最终有效穗数，最终数量必须人工复核。
- 不把 `rice_plant` 检测模型直接当作株高结果，株高还需要独立测量和人工对照。
