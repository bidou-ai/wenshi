# 安全约束

- 程序永远不发送 JAKA 上电、使能、下电或清报警命令。
- AGV 定位超时、急停、报警、被阻挡、运动端口断开或横向偏差超限时，控制器进入错误或阻挡状态并停止运动。
- 倒车必须同时满足 `reverse_motion_allowed`、后雷达已验证，或由经过风险确认的临时显式开关放行。正式配置两者均为关闭。
- 固定示教抵近默认关闭；开启前必须复核停车位置、工作空间、障碍物、示教点、速度和回撤通道。
- D435 只有当 `camera.required_for_route=true` 时才是路线互锁。无论该开关如何，采图均拒绝超过 `camera.frame_max_age_s` 的彩色缓存帧。
- 视觉结果没有运动权限。没有模型、标定、回放与现场验证时，禁止修改 `vision.enabled`。
- `patrol_target.enabled` 默认关闭；它不能绕过底盘、机械臂、相机新鲜度、目标稳定性或固定示教互锁。
- 目标对齐后退只允许发生在 `TARGET_ALIGN_REVERSE` 状态，速度和总位移均有上限；后雷达/现场安全条件未确认时不得启用。

任何现场故障先执行 `stop`，确认机械臂和底盘停止后再诊断。不要通过修改配置绕过报警或姿态限制。
