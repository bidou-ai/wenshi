# 表型数据结构

表型运行与旧 `targets/T*/far.jpg/near.jpg` 原型分开保存。运行目录使用原子 JSON 和媒体写入；所有株号和文件路径必须留在运行根目录内。

```text
runtime/runs/run_<timestamp>/
  run.json
  events.jsonl
  agv.csv
  jaka.csv
  plants/<plant_id>/
    plant.json
    review.json
    captures/{left,center,right}/
      color.jpg
      depth.png                 # 可选；没有深度时明确缺失
      frame.json
    traits/plant_height.json
    traits/effective_panicle_count.json
```

`plant.json` 记录株号、Tag、区域、行、观测组和视角状态。`frame.json` 记录帧时间、设备元数据、质量与 Tag 证据。`plant_height.json` 保存自动/人工路径和值、补偿、质量和原因；`effective_panicle_count.json` 保存候选组、计数证据、复核值和差异。`review.json` 保存单株复核状态和时间。

空值必须保留为空或 `null`，不能用估计值填充。正式结果分别以人工 `reviewed_value_m` 和 `reviewed_count` 为准；没有复核时不产生正式值。
