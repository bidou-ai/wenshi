# 标定说明

正式表型任务需要可追溯的现场标定证据。当前所有下列关键值仍未完成，`phenotyping.enabled` 必须保持 `false`。

| 项目 | 需要记录 | 当前状态 |
| --- | --- | --- |
| Tag 映射 | 32 个 Tag ID、株号、观测组与可见性 | 固定编号已配置，现场照片未发布 |
| Tag 实际尺寸 | `physical_size_m` 实测值与测量证据 | 黑色外框按 0.090 m 配置，待现场照片复核 |
| Tag 后端与朝向 | 可用 `tag25h7` 后端、`upward`/`side` | 当前机器后端未安装，朝向未验收 |
| 水面补偿 | 每株或区域 `slot_top_to_water_m` | 未测量 |
| 16 点停车 | 路线段、沿线距离、减速与触发距离 | 未标定 |
| 表型姿态 | `left`、`center`、`right` 的独立可复现姿态 | 未标定 |
| 相机 | 内参、深度尺度、RGB-D 对齐与帧时间 | 未形成证据 |
| 手眼关系 | D435 与机械臂/参考坐标关系 | 未形成证据 |

完成一项时，保存原始测量记录、操作者、日期、设备/软件版本和配置变更。先逐项验证，再以单 Tag、单视角、一组两株、16 组、32 株的顺序扩大；缺项、过期或矛盾证据必须回到复核，不得以推测值继续。

## 株高测试的可追溯文件

项目内不要求把现场照片复制到训练集。需要打印或准备的已知距离基准目标、直尺和 Tag 说明放在 `docs/现场资源/README.md`；现场照片放入 `runtime/height_tests/setup_<timestamp>/tags/` 或 `runtime/height_tests/run_<timestamp>/reference/`。程序自动生成的逐株证据在 `runtime/height_tests/run_<timestamp>/plants/<plant_id>/views/<view>/`。

Tag 外框实际边长按 90 mm 记录（中间编码区约 60 mm 不能作为 tag_size），family 固定为 `tag25h7`。本机 OpenCV 若没有 `DICT_APRILTAG_25h7`，必须安装并验证 `pupil_apriltags` 或 `apriltag` 后端，不能用其他字典替代。

当前一键株高运行尚未接入实时 Tag 后端。setup 中的 Tag 照片只证明人工身份绑定，不能提供当前 RGB-D 帧里的 Tag 位姿；因此 M1 `tag_panicle_3d` 在后端安装、实时识别、外框角点和姿态链路全部验证前必须保持 `needs_review`。明日第一轮可先验证 M2 `depth_roi_envelope`，但不能据此声称 Tag 标定完成。
