# 标定说明

正式表型任务需要可追溯的现场标定证据。当前所有下列关键值仍未完成，`phenotyping.enabled` 必须保持 `false`。

| 项目 | 需要记录 | 当前状态 |
| --- | --- | --- |
| Tag 映射 | 32 个 Tag ID、株号、观测组与可见性 | 未确认 |
| Tag 实际尺寸 | `physical_size_m` 实测值与测量证据 | 未确认 |
| Tag 后端与朝向 | 可用 `tag25h7` 后端、`upward`/`side` | 未确认 |
| 水面补偿 | 每株或区域 `slot_top_to_water_m` | 未测量 |
| 16 点停车 | 路线段、沿线距离、减速与触发距离 | 未标定 |
| 表型姿态 | `left`、`center`、`right` 的独立可复现姿态 | 未标定 |
| 相机 | 内参、深度尺度、RGB-D 对齐与帧时间 | 未形成证据 |
| 手眼关系 | D435 与机械臂/参考坐标关系 | 未形成证据 |

完成一项时，保存原始测量记录、操作者、日期、设备/软件版本和配置变更。先逐项验证，再以单 Tag、单视角、一组两株、16 组、32 株的顺序扩大；缺项、过期或矛盾证据必须回到复核，不得以推测值继续。
