# 项目状态

更新时间：2026-09-16。

## 一键株高测试通道

已新增 `scripts/start_height_test.sh` 和 `app/wenshi_patrol/height_test/`。它独立保存 RGB-D、双 YOLO 输出、M0-M5 方法结果和 HTML/CSV/文本报告，支持 `setup`、`arm-only`、`full-route`、`replay`、`report`。当前配置登记 32 株，其中 A、B-L、B-R 共 24 株主动检测，C 排 8 株保留 Tag 但排除检测。该工具已通过无硬件单元测试；现场可行性仍需按报告四层状态验收，不能把离线测试当作正式精度结论。

## 已有离线软件基础

- 配置、预检和调度已采用 32 株、16 个观测组的拓扑；每组两株、每株恰好一次覆盖。
- 表型运行目录、三视角媒体、帧元数据、trait JSON 和复核数据可由硬件无关模块处理。
- 株高支持三维路径弧长、补偿优先级和人工复核；有效穗支持候选分组、合并、拆分、状态和证据计数。
- 后台可只读查看表型运行并导出 CSV。
- `daily-check` 已改为遍历全部原始与规范化数据会话，任一会话存在非法类型或标注状态都会失败，避免只看最新目录造成漏检。
