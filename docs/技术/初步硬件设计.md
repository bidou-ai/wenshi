# 初步硬件设计

## 目标链路

```text
四排八株、32 个 Tag
        |
AGV 底盘 -- 机器人内部网络 -- JAKA 机械臂 -- 末端 D435
        |                                  |
        +--------------------------- Windows 相机服务 :18080
                                             |
                                  Ubuntu/VMware 双网络路径
```

该图是现行初步设计和待验证边界，不是已完成的硬件标定图。32 个 Tag 对应四排各八株；16 个逻辑停车组由左右通道各八组组成，而不是 32 个地图站点。

## 组件与接口

- AGV 状态和运动接口使用当前配置的 `192.168.192.5:19204` 与 `192.168.192.5:19205`。
- JAKA 使用当前配置的 `192.168.192.160:10001`；机械臂末端携带 D435。
- 直连 D435 的 Windows 工控机运行 `windows/windows_realsense_server.py`，对机器人内部网络提供 HTTP RGB-D 与 `/health`，当前地址为 `192.168.192.203:18080`。
- Ubuntu/VMware 侧保留机器人内部网络路径用于设备服务，并保留独立的外网/Wi-Fi 路径；实际网卡、路由、网关和防火墙规则须现场确认，不能写作已验收。

AGV 地图和沿线进度负责粗定位，Tag 负责局部身份与触发。16 个停车组的路线段、沿线距离、减速距离和触发距离仍为 `null`；D435 相机参数、手眼关系、表型姿态和水面补偿也未标定。
